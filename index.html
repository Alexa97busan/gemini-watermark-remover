디테일 보존.

흐리게 덮는 대신, 마크가 합성된 방식을 거꾸로 계산해 원래 픽셀을 되살립니다.1

1놓기이미지를 끌어다 놓거나 선택하세요.
2확인슬라이더로 전후를 비교하세요.
3저장다운로드를 누르면 끝.
  1. Gemini는 로고를 반투명하게 합성합니다(결과 = α·로고색 + (1−α)·원본). 로고의 알파맵을 알고 있으므로 이 식을 거꾸로 풀어 원래 픽셀을 복원합니다.
  2. 자국이 살짝 남으면 결과 카드의 세부 조정에서 강도와 로고 밝기를 바꿔 보세요. 엉뚱한 곳을 잡았다면 위치 직접 지정을 누른 뒤 이미지에서 마크를 클릭하세요.
  3. 저장 설정에서 형식(PNG·JPG·WEBP), 가로 크기, 비율을 고르면 모든 다운로드에 적용됩니다. 비율을 고르면 가운데를 기준으로 잘리고, 미리보기에 잘릴 영역이 어둡게 표시돼요. 원본보다 크게 늘리지는 않습니다.
  4. 눈에 보이는 마크만 지웁니다. 이미지 안에 숨겨진 SynthID 디지털 워터마크는 그대로 남습니다. 본인이 만든 이미지를 깔끔하게 쓰는 용도로 사용해 주세요.
